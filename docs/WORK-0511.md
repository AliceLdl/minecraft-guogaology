# WORK-0511 · 新方块「软糖罐 / Gummy Jar」

用户需求（原话）：**以 MC 原版的陶罐为基础，制作新方块软糖罐，样式为玻璃罐子内部装有大量彩色软糖，
挖掘后掉落随机 1~3 个软糖；代替素面果糕生成在紫菜桌上。**

## 一、成品

| 项目 | 内容 |
|---|---|
| 注册名 | `guogaology:gummy_jar`（中文「软糖罐」/ 英文「Gummy Jar」） |
| 骨架 | 原版陶罐（`decorated_pot`）实测碰撞盒 `box(1,0,1,15,16,15)` = 14×16×14 居中 |
| 基类 | `TransparentBlock`（玻璃罐：不吃环境光遮蔽，`getAmbientOcclusionLightLevel = 1.0`） |
| 模型 | `ambientocclusion: false`，三段几何：**罐身 body**（y 0~12，UV 侧面 16×16）/ **肩 shoulder**（y 12~14）/ **罐口 neck**（y 14~16）+ 金属瓶盖贴图 |
| 掉落 | 掉落表 `rolls = uniform 1..3`，四条等权条目 ⇒ **1~3 个随机软糖** |
| 软糖池 | `amber_guogao` / `berry_guogao` / `lime_guogao` / `azure_guogao` |
| 生成 | 紫菜桌（`LaverTableFeature.tableGummy`）上**代替素面果糕** |

美术迭代（按用户逐轮反馈定稿）：方块形 → 陶罐形三段几何；软糖不再浮空；配色**红橙黄为主 + 少量绿/紫、无蓝**；
糖量减少（不冲到瓶口）；不做小熊（空间不够）⇒ 画成**一堆模糊的彩色像素**、不追求颗粒分明；**俯视恢复金属瓶盖**。
贴图为 32×32 小图集（罐身/肩/盖裙/盖顶/罐口内/罐底六块），只由单一用途脚本 `scratch/make_gummy_jar_art.py` 生成
（遵守「不许重跑整套贴图生成器」纪律）。

## 四、踩到的坑（已修，值得记住）

`tools/prepare_port_sources.py` 对 `*Block.java` 用**单行正则**剥掉 `MapCodec` 字段与 `codec()` 覆写
（26.3 的 Block 基类已无 `codec()`）。我第一版把 `@Override` 和方法体写成了**多行** ⇒ 正则没匹配到 ⇒
`CODEC` 字段被删而 `codec()` 覆写留下 ⇒ javac 两错（「方法不会覆盖超类型方法」+「找不到符号 CODEC」）。
**修法：照抄 `FruitJellyBlock` 的单行写法**（`@Override public MapCodec<…> codec() { return CODEC; }`），
适配器随即正确剥离，javac 0 错。⇒ 新增 Block 类时**格式要与现有样例完全同形**，否则适配器静默失效。
