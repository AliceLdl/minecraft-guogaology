# WORK-0504 · 震惊瘫坐之地「局部海平面/盆地注水」

## Scope
用户授权把 26.3 工程中做好的「震惊瘫坐之地·大型水域」并入主 mod。改动只触及**表界**
的单一群系 `guogaology:shocked_slump_land`，巨构里界/果糕地府内容零改动。

## Change
- 新增 `ports/common/main/dev/guogaology/outer/world/SlumpWaterField.java`（NormalNoise 版；26.2/1.21.11 用）
- 新增 `ports/26.3/src/main/java/dev/guogaology/outer/world/SlumpWaterField.java`（Noise/builder 版；26.3 用）
- `LhoChunkGenerator`（common + 26.3 override）各 6 处定点：
  1) `SHOCKED_SLUMP_BIOME` key；2) `NoiseCache` 增加 `slumpBed` 噪声；3) `blockStateOf` 增加 `case 9 = minecraft:water`；
  4) `carveLhoVoid` 内以同一 `ColumnSink` 增加第三遍注水；5) `logSlumpWater` debug 日志；6) `WorldBiomeGrid` 增加 `SHOCKED` 位 + `isShockedSlump`。
- `gradle.properties`：mod_version 0.5.3.0 → 0.5.3.1。

## 算法（与前序 26.3 工程实现逐位相同）
- 水位 L=38：真实存档 14500 区块 / 740,999 目标群系列推演（被淹列 ≈6.47%、新增水 ≈153k、最大连通片 ≈431 格）。
- 逐列纯函数：quart 群系预筛 → 扫顶 h → h<38 注水 (h,38] → 海床顶面 1 格换沙/沙砾（复用 `surfaceKind` 斑块判据换新盐）。
- 边界防漏：8 邻域守门；邻列高度读不到时按水位 quart 取样仍是本群系 ⇒ 放行（同水位连通），外族 ⇒ 放弃该列（不许接缝）。
