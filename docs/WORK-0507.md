# WORK-0507 · 竖井外圈石壳 + 康威链岩螺旋台阶（四朝向箭头）

承接 `docs/HANDOFF-0507.md` 的断点（上一轮 ① 已做、② 做到一半）。

## 需求（用户）

1. **石壳**：大数表界地表「无穷降链」3×3 竖井外圈加一圈石壳（5×5 去掉 3×3 = 正好 16 格），
   从地表封到井底，**防止井与周边洞穴/空腔联通**。
2. **台阶**：螺旋楼梯的台阶统一改用「康威链岩」`guogaology:conway_link`；该方块支持
   **四个水平朝向**，且台阶的朝向 = **下一级（低一格）台阶所在的方向** ⇒ 箭头始终指着往下的路。

设计要点（避免跨映射坑）：`conwayStep` **刻意不引用宿主方块类**，而是
`BuiltInRegistries.BLOCK.getValue(GuogaologyMod.id("conway_link"))` + 遍历状态属性找 `"facing"`；
找不到属性就返回默认状态 ⇒ **1.21.1 目标优雅退化**成「无朝向的普通康威链岩」，不需要为旧映射新增方块类。

seed `-1005030225547044542`，±640 格）：

```

违反：石壳=0 井内非空气=0 层内台阶数/总级数=0 朝向未指向下一级=0 台阶落在正中=0   ⇒ 断言全部通过
```

- 每孔 163 级台阶（`top-1 - (minY+1) + 1`，35×163 = 5705 ✔），每层恰好一级、且不在 3×3 正中。
- 石壳：35 × 16 格 × 165 层 = 92400 ✔，从地表一直封到井底，一格不漏。

**conwayStep 端到端探针**（`.toolchain/shaftverify/ConwayStateProbe.java`，真实注册表 + 真实 `ConwayLinkBlock`）：

- `directional`：`guogaology:conway_link = ConwayLinkBlock`（默认状态属性 `EnumProperty{name=facing, values=[north,south,west,east]}`）；
  入参 `0/1/2/3` → `north/east/south/west`，非默认朝向的「改状态」均为真 ⇒ 全部通过。
- `plain`（把同名 id 注册成**没有 facing 属性**的普通方块 = 1.21.1 的情形）：四个入参都**原样返回默认状态** ⇒ 退化路径成立。
- `precheck`：未初始化注册表就调用 `conwayStep` ⇒ 抛 `ExceptionInInitializerError` ⇒ 结果确实来自注册表。
- （探针专属技巧：只置 `Bootstrap.isBootstrapped=true` 让注册表初始化，**不跑** `Bootstrap.bootStrap()`，
  否则它会在结尾冻结注册表，之后 `Block` 构造/注册都会抛
  `IllegalStateException: This registry can't create intrusive holders`。）

**朝向约定以真实 26.3 原版数据为准**：`assets/minecraft/blockstates/furnace.json`、`dispenser.json` 中
模型朝北用 `y=0`、朝东用 `y=90` ⇒ blockstate 的 `y = 0/90/180/270` 即 东/南/西/北；

`east→0, south→90, west→180, north→270` 与代码里的朝向映射一致。

**四目标生成源核对**：1.21.11 / 26.2（吃共享源）与 26.3（吃覆写）都带上 `SurfaceShaftField::conwayStep`；
