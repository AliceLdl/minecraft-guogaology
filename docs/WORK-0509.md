# WORK-0509 · 竖井石壳与最高台阶平齐（石壳整体降 1 格）

## 需求（用户）

> 「现在周围的石头保护层的高度比中间的旋转楼梯的最高格高出1格，看上去有点奇怪，改成平齐」

用户选定 **B 方案**：把**石壳整体降 1 格**（不是抬高最高台阶）；并且**只改生成器**，
已生成的那座竖井不动（已生成区块永不重算）。

## 改前实测几何（只读解码存档，非推断）

竖井中心 `(-230,-118)`（`新的世界 (1)`，种子 -2037430484874561583），井口层 `top = 61`：

| 部位 | 顶面 y |
|---|---|
| 周围草地 | 62 |
| **石壳（保护层）** | **62**（与草地齐平） |
| **螺旋楼梯最高一级台阶** | **61** |

⇒ 石壳比最高台阶正好高 1 格 —— 就是用户看到的那个「奇怪」的 1 格。原因：石壳循环从 `top` 开始写，
而台阶循环从 `top-1` 开始写。

## 改动

`ports/common/main/dev/guogaology/outer/world/SurfaceShaftField.java`（javadoc 同步）：

```java
// 石壳：起点 top-1（原来是 top）
for (int y = top - 1; y >= minY; y--) { ... 16 格石壳 ... }
```

- 石壳改为从地表**下一格**封到井底 ⇒ **石壳顶面 = 最高台阶顶面 = `top`（平齐）**。
- `top` 那一层保留原地表（所以从上面看，石壳顶面比周围草地低 1 格 —— B 方案的预期效果）。
- 台阶循环不动（最高台阶仍在 `top-1`）；挖空循环不动（井口仍在 `top`）。
- `top - 1 >= minY` 有保证：前面已排除 `top <= minY`。
