# WORK-0514 · 软糖罐：绿/紫软糖在两张面上都出现（且俯视可见）

用户反馈（原话）：**「顶面糖堆有紫色没有绿色，侧面糖堆有绿色没有紫色……」**

## 一、真因

1. **稀有绿/紫是纯随机抽的** ⇒ 一张面可能几乎全被绿占、另一张全被紫占（数量少时随机波动极大）。
2. 加「绿紫交替」后仍有问题：**孤立的稀有像素会被 3×3 众数滤波吃掉**
   （实测侧面只剩 1 个紫像素）。
3. 再修「整块 2×2 同色」后，**俯视又看不见紫**：俯视时金属盖（8×8）盖住顶面中间，
   只看得见盖外那一圈；随机撒点把稀有糖撒到了被盖住的中部（以及被挖掉的圆角外）。

## 二、修法（都在 `scratch/make_gummy_jar_art.py`）

1. **整块 2×2 同色**：稀有糖以 2×2 同色块出现 ⇒ 众数滤波吃不掉。
2. **绿紫交替**：每张面都同时有两种（`rare_color()` 按序号在绿/紫之间交替）。
3. **撒点方式分两种**：
   - 侧面：**模数撒点** `((bx/2)*3 + (by/2)*5) % 7 == 0` —— 行列都铺开
     （等间距按序号挑会退化成同一列，试过，不行）。
   - 顶面：**显式放在金属盖之外那一圈** —— `{(4,0), (0,4), (10,4), (4,10)}` 四个位置，
     上/左/右/下各一颗、绿紫交替 ⇒ 俯视一定能同时看到绿和紫。
4. **断言（构建前就拦住）**：
   - 每张糖面必须同时有绿和紫；
   - **顶面「金属盖之外那一圈」也必须同时有绿和紫**（这条正是用户看到的现象）。
