# 版本号规则（VERSIONING）

## 一、现行规则（用户 2026-10-10 指定）

版本号是**四段**：`0.5.<minor>.<patch>`。

- **小改动只加第四位**：`0.5.4.0` → `0.5.4.1` → `0.5.4.2` …（不需要问，直接加）
- **第三位只在用户明确说的时候才加**：`0.5.4.x` → `0.5.5.0`
- 第一位/第二位（`0.5`）沿用旧系列，不轻易动

- 工作记录文件名（`WORK-0517.md` 之类）是**会话编号**，不是版本号，因此不改名。

## 三、发布产物命名

构建产物跟着版本号走：`guogaology-dimension-<mc版本>-<版本号>.jar`，
例如当前为 `guogaology-dimension-26.3-0.5.4.0.jar`。
