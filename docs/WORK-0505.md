# WORK-0505 · 「无穷降链」+ 葛立恒藤可攀爬

## Scope（用户本轮两项要求）
1. 新结构「无穷降链」：大数表界地表群系生成（排除 LHO 空境/边缘）——
   3×3 的孔从地表一直通到虚空，内壁一圈序石螺旋楼梯。
2. 葛立恒藤（`guogaology:graham_vine`）补可攀爬（与原版藤蔓一致）。

## Change
- 新增 `ports/common/main/dev/guogaology/outer/world/SurfaceShaftField.java`
  （纯几何逐区块哈希：每 160×160 网格至多一个候选孔位 ≈3.9/km²；孔位 3×3 必须整体落在本区块内才写，
  lho_void/lho_edge 处放弃；孔壁为序石，每层 1 步沿 8 边缘格顺时针）。
- `LhoChunkGenerator`（common + 26.3 override）各 +1 处第四遍接线 + `WorldBiomeGrid.isVoidOrEdge`。
- 新增 `src/main/resources/data/minecraft/tags/block/climbable.json`：
  `{"replace": false, "values": ["guogaology:graham_vine"]}` —— 26.3 的攀爬判定是
  **标签驱动**（真实字节码 `LivingEntity#onClimbable` = `state.is(BlockTags.CLIMBABLE)`
  + trapdoor 特例）；藤方块本体已是原版 `VineBlock` 类，但 mod id 不在 ^tag 内 ⇒ 不可攀。
  标签 `replace:false` 会与原版表合并，四目标共用。
- `gradle.properties`：mod_version 0.5.3.1 → 0.5.3.2。

## Build/验证
- 26.3 off-loom 构建：javac 0 错，`guogaology-dimension-26.3-0.5.5.jar`（4.2MB）；
  仓库三审计全绿。
- **未验证**：1.21.1 / 1.21.11 / 26.2 目标（沙箱 loom zipfs 限制，remap=false 才能走离线管线）；
- **未验证**：游戏内视觉/攀爬手感 —— 部署后进新世界验收：
  竖井约 3.9/km²（约 1/257 块区域一个）；藤的攀爬=持有方块走上去直接爬（原版手感）。
