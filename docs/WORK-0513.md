# WORK-0513 · 软糖罐造型重做（罐肩半玻璃半金属 / 俯视糖飘空 / 侧视糖堆形状）

本轮用户连着给了四条反馈，最终方向是：

1. **「贴图瓶颈那一块为什么一半是玻璃的一半是金属的」**
2. **「俯视看到的软糖像是飘在半空中」**
3. **「侧视图的软糖堆最好做成两侧低中间高，现在是一侧低一侧高看上去有点奇怪」**
4. **「我说的叠是指里面软糖部分用三个长方形拉伸叠在一起，这是问题，应该用一个长方形去掉不需要的部分」**
   ＋「两侧不应该下降得那么陡峭，两侧只低一点就够了」＋「糖堆顶部高的地方有点窄了」

## 一、真因与修法

| 反馈 | 真因 | 修法 |
|---|---|---|
| 罐肩一圈半玻璃半金属 | 图集里 **罐肩分面与盖顶分面重叠**（盖顶后画，覆盖了罐肩右边 4 像素）⇒ 那个面同时采到玻璃和金属 | 重排图集，**七个分面互不重叠**，并在生成脚本里加**断言**：重叠直接报错退出 |
| 俯视软糖飘空 | 旧模型把糖堆**画在罐身顶面 y=12**（= 罐口平面）⇒ 俯视看着像贴在罐口 | 模型改成**空心玻璃罐**（罐底 + 四片罐壁 + 罐肩 + 盖），糖是**罐内一个真实盒体**，顶面在 **y≈7.2**（罐口 y=16）⇒ 糖在罐内深处 |
| 侧视糖堆一侧低一侧高 | 旧图集的糖堆是单坡 | 糖堆改成**平顶土丘**：中间一大段在最高处，两侧只缓降 1~2 格（用户：「两侧只低一点」「顶部别太窄」） |
| 三个长方形叠起来 | 我第一版把糖做成三层方盒 | 糖改成**一个长方形盒体**，靠贴图**挖空**做出糖堆轮廓：侧面挖成土丘轮廓、顶面四角挖圆 |

## 二、现在的结构（8 个元素）

| 元素 | 范围 | 说明 |
|---|---|---|
| 罐底 | `(1,0,1)-(15,1,15)` | 玻璃底 |
| 四片罐壁 | 各 1 格厚，`y=1..12` | 外侧玻璃（高光/竖纹）、内侧偏暗；底面省掉 |
| 罐肩 | `(2,12,2)-(14,14,14)` | 纯玻璃收口（顶面采它自己那一行均匀玻璃） |
| 金属盖 | `(4,14,4)-(12,16,12)` | 盖裙 + 盖顶金属；底面省掉 |
| **软糖** | `(2.1,1.02,2.1)-(13.9,7.2,13.9)` | **只有一个**，侧面 = 土丘轮廓、顶面 = 圆角糖面 |

## 三、两个必须记住的坑

1. **图集分面重叠 = 一个面同时采到两种材质**。上一版 `SHOULDER ∩ CAP_TOP` 就是这样。
   现在 `make_gummy_jar_art.py` 里 `assert_disjoint()` 会在重叠时直接报错，构建前就拦住。
2. **窄面必须取窄切片**。罐肩顶面（12×12）若直接采 12×2 的罐肩侧贴图，那排亮格会被拉成**竖条**（第一版渲染就是这个毛病）。
   现在：1 格宽的面/罐壁顶面那一圈，都只采贴图里对应的**一行或两列**。
